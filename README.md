**Описание:**
Текстовый хоррор-триллер, где каждое слово может стать последним. Перехитри 40 маньяков, решай жуткие головоломки и выживи в этой опасной переписке!

**Как играть:**

*   **Управление:**
    *   Левая кнопка мыши / Тап по экрану — ваш единственный инструмент.

*   **Инструкции:**
    *   **Читайте диалог:** Внимательно следите за перепиской с опасным собеседником.
    *   **Выбирайте ответ:** Когда появятся варианты, выберите тот, который, по вашему мнению, поможет вам выжить. Нажимайте на кнопки с текстом, чтобы ответить.
    *   **Решайте мини-игры:** Между диалогами вас ждут головоломки. Следуйте инструкциям на экране (перетаскивайте предметы, нажимайте в нужный момент и т.д.).

Ваша главная цель — перехитрить каждого из 40 противников и остаться в живых. Удачи!
